# Writing SQL 101

This is a small 1 hour tutorial to learn basic SQL using Apache Spark in a notebook.

Everything is setup to run inside visual studio code.

## Requirements

- Visual Studio Code
- Dev Containers extension
- Container runtime (tested on Docker and Podman)

## How to starts

1. Open this repo in vscode
2. `F1` -> `Dev containers: Rebuil and Reopen in Container`. Wait for it to create a container with all requirements
3. Open `writing-sql-tutotial.ipynb`
